# Annuaire Justice

Application web de recherche dans un annuaire de juridictions françaises
(greffes, parquets, établissements pénitentiaires…).

- Recherche instantanée par ville, juridiction, service, numéro ou adresse mail
- Ajout / suppression de juridictions, services et contacts
- Notation des numéros (✓ décroche / ✗ ne répond pas) avec priorisation automatique
- Données stockées localement et synchronisées via Google Drive (scope `drive.file`)

**Aucune donnée n'est publiée dans ce dépôt** : le fichier de données reste dans
le Google Drive de l'utilisateur.
